# Car_Sales_Data_Analysis-EDA-Project- 

📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a used car sales dataset containing 9,500+ records from Ukraine. The goal is to analyze different factors affecting car prices and customer preferences.

🎯 Objectives

The main objectives of this project are:
Identify which type of cars are sold the most
Analyze the relationship between price and mileage
Compare registered vs non-registered cars price distribution
Study price trends based on engine volume and engine type
Perform correlation analysis between all numeric features using heatmap
Understand the overall distribution of car prices

🛠 Tools & Technologies Used

Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

📊 Key Analysis Performed

Data loading and inspection
Missing value handling
Data cleaning and preprocessing
Univariate and bivariate analysis
Correlation heatmap
Visualization of important features affecting car prices

🔍 Key Insights (Example)

Car price is highly influenced by year of manufacturing and engine volume
Mileage has a negative correlation with price
Registered cars tend to have higher selling prices compared to non-registered cars
Certain engine types are more preferred and sold more frequently

🚀 Conclusion


This project helped in understanding how to approach a dataset, clean it, visualize important trends, and generate meaningful business insights using Python.
